# LANDING-DEAD-FORMS-01. Две страницы закрыты

12 сентября 2026. Страницы не удалял, ссылок не добавлял, `/apply` не трогал, не деплоил.

---

## 1. `game-flow.html` — поле работает, правда сказана рядом

Поле осталось рабочим: не отключено, не переведено в режим чтения, текст вводится. Под ним появилась одна фраза:

> Эта заметка живёт только в этой вкладке. Закроете её — заметка исчезнет: она нигде не сохраняется.

**На всех двенадцати языках страницы** — en, fr, ru, es, uk, it, de, he, pt, ka, ro, pl. Фраза добавлена ключом `tasting_notes_local` в живой файл переводов, а не вписана в страницу по-английски: иначе на одиннадцати языках из двенадцати она бы висела чужой строкой.

Фраза и поле лежат **в одном блоке разметки**, проверено. Это важно: поле находится внутри экрана-витрины, который показывается не сразу, и появись фраза в другом месте — человек увидел бы поле без предупреждения. Теперь они появляются и исчезают вместе.

## 2. `tamada-preview-xk7m9q2026.html` — закрыта от поисковиков, поля отключены

Добавлен запрет индексации: `<meta name="robots" content="noindex, nofollow">`.

Отключены **все двадцать два поля**, включая имя гостя и телефон гостя. Способ тот же, что на прототипах: поле остаётся видимым как часть картинки будущего экрана, но принять чужие данные больше не может.

Страница на месте, ссылок на неё по-прежнему нет нигде, адрес не менялся.

## 3. ПРОВЕРКА ФАКТОМ

Обе страницы подняты на локальном сервере и открыты настоящим браузером.

**`game-flow.html`**, фраза читается на трёх проверенных языках:

```
game-flow en: This note lives only in this tab. Close it and the note is gone — nothing is saved anywhere.
game-flow ru: Эта заметка живёт только в этой вкладке. Закроете её — заметка исчезнет: она нигде не сохраняется.
game-flow de: Diese Notiz existiert nur in diesem Tab. Schließen Sie ihn, ist die Notiz weg — sie wird nirgendwo gespeichert.
поле и фраза в одном блоке: true
поле отключено: false | только чтение: false
```

**`tamada-preview-xk7m9q2026.html`**:

```
tamada robots: noindex, nofollow
  #guest-name-inp отключено: true
  #guest-phone-inp отключено: true
  #custom-time-inp отключено: true
  поля: { всего: 22, отключено: 22 }
```

Значение `robots` прочитано **из готовой страницы в браузере**, а не из исходника: запрет действительно доехал до разметки, а не остался текстом в файле.

Файл переводов после правки разбирается без ошибок.

## 4. ЧТО ЭТО НЕ ЗАКРЫВАЕТ

Запрет индексации — просьба к поисковику, а не замок. Страница по-прежнему открывается всем, кто знает адрес. Поля больше не примут данные, и этого достаточно для того, ради чего задача ставилась; но если нужно, чтобы страницу нельзя было **открыть**, это отдельное решение и другой механизм. Сам не делал.

Ещё: страницы, которые поисковик уже успел проиндексировать, из выдачи уходят не мгновенно. `noindex` действует со следующего обхода.
